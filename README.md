# B4HG Company Limited - Website

A professional and colorful website for B4HG Company Limited, a global supplier of hydraulic hose and equipment.

## Features

- **Modern Design**: Professional color scheme with blue and teal gradients
- **Responsive Layout**: Mobile-friendly design that works on all devices
- **Complete Sections**:
  - Home/Hero Section
  - About Us
  - Services
  - Products
  - Contact
  - Footer with WhatsApp Integration

- **Interactive Elements**:
  - Smooth scrolling navigation
  - Hover animations
  - Contact form
  - WhatsApp integration
  - Social media links

## Getting Started

1. Clone or download this repository
2. Make sure the `images` folder contains `store.jpg`
3. Open `index.html` in your web browser
4. Deploy to GitHub Pages or your hosting provider

## Setup Instructions

### For GitHub Pages Deployment:

1. Create a new GitHub repository named `b4hg-website`
2. Upload all files to the repository
3. Go to Settings → Pages
4. Select "main" branch as the source
5. Your site will be available at: `https://yourusername.github.io/b4hg-website/`

## Customization

### To change colors:
Edit the CSS variables in `styles.css`:
```css
:root {
    --primary-color: #1e40af;
    --secondary-color: #0891b2;
    --accent-color: #f59e0b;
    /* ... other colors ... */
}
```

### To update contact information:
Edit the contact section in `index.html`:
```html
<p>+234 (0) 244 436 1133</p>
```

### To add more products/services:
Duplicate a `.product-card` or `.service-card` div and update the content
